# vaulttext

Vault host/text network string helpers for config audits.

**Site:** https://theworker02.github.io/vaulttext/

## Install / run

```bash
git clone https://github.com/theworker02/vaulttext.git
cd vaulttext
node src/cli.js
node --test
```
